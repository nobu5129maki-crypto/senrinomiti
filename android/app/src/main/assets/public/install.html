千里の道も一歩から

アプリ版 v1.0.33

スマホにアプリを入れると、画面を消していても歩数がたまります。

3ステップ 約1分 無料 Play ストア不要

まず Chrome で開いてください

いまは note などのアプリの中でこのページを見ています。このままではアプリを入れられません。

Chrome で開く

  1. 1

    アプリをダウンロード

    アプリをダウンロード

    「悪影響を及ぼす可能性があります」と出たら、「ダウンロード」を押してください。Google の定型の確認で、異常ではありません。

  2. 2

    ダウンロードしたファイルを開く

    画面の上に出る通知 senrinomiti.apk をタップします。これがアプリのファイルです。

    通知が見つからないときは、Chrome 右上の ⋮ → ダウンロード から開けます。「もう一度ダウンロードしますか？」と出たら キャンセルし、一覧のファイルを開いてください。

  3. 3

    「インストール」を押す

    「デバイスを保護するため…」と出ても大丈夫です。小さい文字の 詳細 → インストールする を押します。

    デバイスを保護するため
    アプリをブロックしました

    ここを押す：詳細 → インストールする OK（押さない）

    大きい OK は「やめる」なので押さないでください。「この提供元のアプリを許可」と出たら、スイッチをオンにして戻ります。

終わったら、ホーム画面の 千里の道 を開いてください。

うまくいかないとき

「アプリはインストールされていません」と出るときは、以前入れた版を先に削除してください。

以前入れた版を削除

「この提供元を許可」の画面が出なかったときは、ここから許可できます。

インストールの許可を開く

手動で行う場合：設定 → アプリ → Chrome → 不明なアプリのインストール → オン

iPhone は ホーム画面に追加するだけで使えます。App Store は不要です。
